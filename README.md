# Vsyakaya_huynya — commercial signal research

Этот репозиторий используется как постоянный журнал независимых исследований потенциально коммерческих информационных сервисов.

Цель: не придумывать очередной большой SaaS, а находить уже доказанные на других рынках механики, которые можно применить в России и монетизировать за счёт раннего, редкого или обязательного бизнес-сигнала.

## Текущие три исследования

1. **Реестр уведомлений о начале предпринимательской деятельности** — можно ли получать ранние лиды на фактически открывающиеся точки бизнеса до открытия.
2. **Алкогольные лицензии / заявления HoReCa** — можно ли заранее обнаруживать новые рестораны, бары и иные точки общепита до фактического открытия.
3. **ЕРКНМ: проверки, нарушения и предписания** — можно ли превращать обязательную проблему бизнеса в квалифицированный B2B-лид для подрядчика, который эту проблему устраняет.

## Обязательное правило исследования

Никакой пробел в данных нельзя заменять догадкой.

Если обычный web/HTTP-доступ не позволяет полноценно проверить источник, фиксируется статус `BROWSER_PROBE_REQUIRED` и готовится bounded prompt для ChatGPT Work или локального Codex с браузером. Только после фактического браузерного readback источник может считаться проверенным.

Каждое исследование завершается отдельным решением:

- `GO` — есть доказанный коммерческий сигнал и реалистичный MVP;
- `HOLD` — потенциал есть, но остаётся критический неопределённый фактор;
- `KILL` — экономика, тайминг, качество сигнала, доступность данных или конкуренция делают идею нецелесообразной.
