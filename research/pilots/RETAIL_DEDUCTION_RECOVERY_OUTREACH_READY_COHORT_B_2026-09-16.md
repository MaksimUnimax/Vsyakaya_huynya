# Qualification rule before asking for files

Do not send the full sample request immediately.

First obtain five facts:

1. Which one network can they easiest export for 3 months?
2. Rough count and RUB amount of fines/deductions in that period?
3. Main reason families?
4. Which EDI provider?
5. Can they export 20–50 penalty docs plus linked ORDERS/ORDRSP/DESADV/RECADV without a custom IT project?

Only qualified respondents receive:

`RETAIL_DEDUCTION_RECOVERY_SAMPLE_REQUEST_2026-09-16.md`

# Success metric

Do not optimize for messages sent or replies.

Count only:

- process-owner conversations;
- suppliers with material penalty flow;
- bounded sample agreements;
- actual historical data received;
- complete enough samples to compute Tier-A RUB and false-positive RUB.

Target remains:

`10 qualified supplier historical samples`.
