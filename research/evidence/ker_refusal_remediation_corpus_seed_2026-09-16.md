## Immediate signal-quality observations

### Strong

- region 16 tables directly expose refusal class `pp.1` vs `pp.2`;
- region 23 often exposes application + refusal PDF + later permit in one chronology;
- region 38 exposes dense refusal DOCX history;
- region 51 exposes both refusal and later issue/reapplication history;
- regions 34/64/36 expose structured XLS/XLSX refusal registers suitable for batch parsing if download access remains stable.

### Risks already visible

- publication date can lag decision date in some regions;
- company/object can repeat multiple times, so raw count overstates buyer count;
- a refusal can be resolved by the existing team within weeks;
- some pages expose only statutory refusal code without detailed defects;
- source formats and site behavior differ by territory and can change.
